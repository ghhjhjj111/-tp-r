## 👷 工人端｜核心【找活名片】模块（重点）

> 
> 和人才网简历不一样，是蓝领技能名片，鱼泡同款

- 微信一键登录、实名、证件上传（焊工证、电工证等）
- ✅ **工人技能名片**：工种、工龄、擅长工艺、可上岗区域、是否接受出差、期望结算方式、作品照片，名片可分享海报
- 工种多级分类：钢筋、木工、瓦工、水电、吊装、清运、杂工、班组
- LBS 同城、地图找活，筛选：距离、日结 / 周结 / 月结 / 完工结、食宿、工期
- 招工详情、报名、收藏、私信 IM、隐私拨号（保护手机号）
- 记工打卡、工时台账、完工确认、薪资账单、双向评价、拉黑
- 我的名片、我找的活、报名记录、收到邀约

## 🏗️ 老板 / 包工头端（招工发布）

- 实名 / 营业执照双审核
- 发布招工单：工地地址、工种、人数、工期、薪资、食宿、结算、进场时间
- 工种分类选择，可发布班组大包、散工零活
- 工人名片库检索，按工种、距离筛选，主动邀约工人
- 报名列表管理、上岗确认、完工验收、评价工友
- 岗位刷新、置顶、加急、套餐充值，岗位分享海报

## 📂 信息分类模块

后台自定义一级、二级工种分类，地区分类；前端分类导航、分类检索；可单独开启【工程信息】板块（发包、找班组）。

## 🌐 PC 招工网站

独立官网页面：首页招工列表、工人名片库、工种分类、城市切换、招工详情、资讯公告，适合做百度收录引流，H5 和小程序数据完全同源。

## 🧑‍💻 PC 总后台（FastAdmin）

- 用户、招工单、工人名片审核，先发后审开关、敏感词、举报、黑名单
- 工种库、地区、标签、结算类型后台配置
- 变现：置顶套餐、刷新扣费、会员、接单佣金、代理分销
- 财务：充值、订单、流水、提现、对账

- 广告、轮播、公告、消息推送、权限子账号
